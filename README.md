# BD2 FINAL

**Prepará tu final de Base de Datos 2 de forma inteligente.**

Plataforma educativa moderna, interactiva y responsive para estudiar Base de Datos 2.

## ✨ Features
- Dashboard con progreso, racha y XP
- 6 módulos con teoría, SQL, errores frecuentes y tips de examen
- Flashcards con flip 3D y repaso inteligente (fácil/normal/difícil)
- Cuestionarios (múltiple opción, V/F, elegir consulta, interpretar)
- Laboratorio SQL con editor simulado
- Simulacro de final (10/20/30 preguntas, con/sin tiempo + rendimiento por módulo)
- Sesión de estudio 15 min, Repaso inteligente, Favoritos, Errores frecuentes
- Buscador global, Dark Mode, Gamificación (XP, nivel, logros)
- Datos en `src/data/*`, LocalStorage

## 🚀 Stack
React + TypeScript + Vite + Tailwind CSS (v3)

## Desarrollo
```bash
npm install
npm run dev    # http://localhost:5173
npm run build
npm run preview
```

## Datos
- `src/data/modules.ts` (6 módulos, 25 conceptos)
- `src/data/flashcards.ts` (60)
- `src/data/questions.ts` (60)
- `src/data/exercises.ts` (10)
- `src/data/commonErrors.ts`
